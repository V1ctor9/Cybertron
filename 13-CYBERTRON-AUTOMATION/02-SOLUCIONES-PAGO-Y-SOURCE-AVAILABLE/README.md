| Producto | Enlace | Licencia / modalidad | Observación |
|---|---|---|---|
| n8n | https://github.com/n8n-io/n8n | Sustainable Use License / oferta cloud | Código visible y autoalojamiento, con restricciones de uso; revisar uso comercial concreto |
| Make | https://www.make.com/ | SaaS propietario | La cuenta gratuita tiene límites de operaciones y escenarios; comprobar precios vigentes |
| Zapier | https://zapier.com/ | SaaS propietario | Referencia comercial para automatización |
| Dify | https://github.com/langgenius/dify | Dify Open Source License con condiciones adicionales | No asumir Apache/MIT puro; revisar licencia y uso comercial |
| Activepieces Cloud | https://www.activepieces.com/ | Cloud y opciones empresariales | Comparar límites de cloud con el despliegue comunitario |

## Recomendación
Seguir con Make mientras el escenario existente sea suficiente; estudiar alternativas autoalojadas sin migrar hasta medir coste total, mantenimiento y requisitos de servidor.
