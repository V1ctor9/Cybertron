# Cybertron Automation

Área de automatización de procesos y coordinación de flujos de trabajo.

## Objetivo
Diseñar automatizaciones modulares, documentadas y sostenibles para Cybertron y sus proyectos.

## Principios
- Priorizar planes gratuitos y opciones adaptables.
- Separar escenarios por función cuando facilite mantenimiento.
- Documentar límites de uso, costes y dependencias.
- Mantener supervisión humana y recuperación ante errores.

## Líneas de trabajo
1. Inventario de procesos candidatos.
2. Diseño de escenarios Make.
3. Integraciones con servicios y modelos de IA.
4. Pruebas, registro de errores y documentación.
