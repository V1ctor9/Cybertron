# Cybertron Web y Social Media

Área de creación, mantenimiento web y servicios de presencia digital.

## Objetivo
Ofrecer a clientes y proyectos de Cybertron sitios web, mantenimiento y gestión de presencia en redes sociales.

## Líneas de trabajo
1. Investigación de alojamiento gratuito o de bajo coste.
2. Plantillas, diseño y desarrollo web.
3. Mantenimiento, seguridad, copias y actualizaciones.
4. Estrategia y gestión de contenidos sociales.
5. Catálogo de servicios y procedimientos de entrega.

## Estado
Área planificada; evaluar herramientas y costes antes de comprometer servicios.
