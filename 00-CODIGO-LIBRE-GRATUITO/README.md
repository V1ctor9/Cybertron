## Criterios de selección
- Las estrellas son una señal de adopción, no una auditoría de seguridad ni una garantía de calidad.
- El recuento es una captura puntual de la API de GitHub; puede cambiar.
- «NOASSERTION» significa que la API no identificó una licencia SPDX: no asumir que el proyecto es libre hasta revisar LICENSE, avisos de terceros y condiciones de cada componente.
- Antes de instalar: revisar actividad, versiones, dependencias, avisos de seguridad, issues, releases y procedencia del código.
- No copiar secretos, tokens, datos personales ni información sensible al repositorio.
