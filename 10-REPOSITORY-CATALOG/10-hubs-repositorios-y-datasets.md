# Hubs, repositorios y datasets

No todo lo útil vive en GitHub. Este documento reúne hubs y catálogos en los que se publican código, modelos, pesos, datasets, notebooks y aplicaciones.

## Hubs de modelos y datasets
- Hugging Face Hub — https://huggingface.co/ — modelos, datasets, Spaces, documentación y repositorios Git.
- Kaggle — https://www.kaggle.com/ — datasets, notebooks, competiciones y modelos.
- ModelScope — https://www.modelscope.cn/ — modelos, datasets y proyectos de IA; revisar términos por activo.
- GitHub — https://github.com/ — código fuente, ejemplos, herramientas, modelos y documentación.
- OpenXLab — https://openxlab.org.cn/ — modelos y datasets del ecosistema de investigación.
- Ollama Library — https://ollama.com/library — catálogo de modelos empaquetados para ejecución local; comprobar modelo y licencia originales.
- NVIDIA NGC — https://catalog.ngc.nvidia.com/ — contenedores, modelos y recursos acelerados; licencias individuales.
- Google Cloud Model Garden — https://cloud.google.com/vertex-ai/generative-ai/docs/model-garden/explore-models — catálogo de modelos para Vertex AI; disponibilidad y coste dependen del servicio.

## Catálogos de código y descubrimiento
- GitHub Topics — https://github.com/topics/artificial-intelligence
- GitHub Topics LLM — https://github.com/topics/large-language-models
- GitHub Topics agents — https://github.com/topics/ai-agents
- Papers with Code — https://paperswithcode.com/ — artículos, benchmarks y código enlazado; verificar repositorios originales.

- Open Source Initiative — https://opensource.org/licenses — referencia para comprobar licencias aprobadas como open source.
- SPDX License List — https://spdx.org/licenses/ — identificadores y textos de licencias.

## Repositorios de listas comunitarias para descubrir más
- https://github.com/sindresorhus/awesome — índice de listas awesome.
- https://github.com/kyrolabs/awesome-langchain — recursos del ecosistema LangChain.
- https://github.com/kyrolabs/awesome-agents — catálogo comunitario de agentes.
- https://github.com/e2b-dev/awesome-ai-agents — ejemplos y herramientas de agentes.
- https://github.com/dhaulagani/awesome-free-cloud-notebooks — lista comunitaria de notebooks y recursos cloud; verificar cada cuota directamente con el proveedor.

## Política de incorporación
Las listas comunitarias son puntos de partida, no avales. Cada elemento que pase a la lista principal debe enlazar al proyecto original, identificar su licencia y registrar fecha de comprobación. Para datasets, registrar además fuente, fecha de captura, cobertura geográfica, resolución, licencia, restricciones y calidad.
