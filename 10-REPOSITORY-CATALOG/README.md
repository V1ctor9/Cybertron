# Cybertron Open Source Repository Catalog

Catálogo de investigación de proyectos públicos y de código abierto que podrían aportar valor a Cybertron.

## Objetivo
Identificar, evaluar y documentar herramientas reutilizables antes de adoptarlas. Este catálogo no implica aprobación, instalación ni copia automática de código.

## Áreas de vigilancia
- IA, modelos locales, inferencia y evaluación
- Agentes, orquestación, MCP y skills
- Ciberseguridad defensiva, AppSec, SOC, detección y respuesta
- Automatización e integración
- Infraestructura, nube, contenedores y observabilidad
- Geoespacial, satélites y análisis ambiental (Ojo de Dios)
- Energía y datos marinos (Atlas)
- Audiovisual y herramientas para creadores (Semillitas de la Biblia)

## Criterios mínimos de evaluación
1. URL canónica y propietario original.
2. Licencia y compatibilidad con uso comercial.
3. Actividad reciente, mantenedores, releases e incidencias.
4. Dependencias, requisitos de hardware y coste operativo.
5. Riesgos de seguridad, cadena de suministro y privacidad.
6. Uso potencial dentro de Cybertron y nivel de madurez.
7. Prueba aislada recomendada, si procede.

## Estados
- **Por revisar**: candidato descubierto, aún no validado.
- **En evaluación**: licencia, código y dependencias en revisión.
- **Aprobado para prueba**: apto para laboratorio aislado.
- **Aprobado para integración**: validado para un caso de uso concreto.
- **Descartado**: motivo documentado.

## Registro
Usar `REPOSITORY-REGISTER.md` para registrar candidatos. No guardar tokens, claves, credenciales ni datos privados.
