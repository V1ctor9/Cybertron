# Cybertron — Catálogo de tecnología abierta

**Objetivo:** localizar, evaluar y organizar código, modelos, datasets y herramientas que puedan servir a Cybertron y a sus proyectos.

## Estado
- Catálogo inicial de investigación; no equivale a aprobación, auditoría de seguridad ni validación de licencias.
- Los enlaces apuntan a repositorios de sus autores o mantenedores.
- Se priorizarán proyectos mantenidos, documentación clara, instalación reproducible y licencias compatibles con el uso previsto.
- No se instalará ni ejecutará código automáticamente desde este catálogo.

## Reglas de clasificación
1. **Código abierto:** código disponible con licencia que concede derechos de uso, modificación y distribución.
2. **Pesos abiertos:** pesos descargables; revisar por separado licencia, restricciones de uso y disponibilidad de datos/código de entrenamiento.
3. **Código público / source-available:** código visible, pero con condiciones que pueden no cumplir la definición de software libre.
4. **API gratuita:** servicio remoto con cuota o límites; no es software local ni necesariamente gratuito de forma permanente.

## Principio de seguridad
No subir secretos, tokens, claves, credenciales, datos personales ni información sensible. Antes de incorporar un proyecto: revisar licencia, actividad, dependencias, permisos, riesgos de cadena de suministro, requisitos de hardware y coste operativo.
